# Rangiffler (rfr)

Монолит с моками: часть функций настоящая (регистрация, вход, профиль, дружба), часть возвращается из JSON-моков (фото, лайки, лента, статистика).

## Ограничения

- Моки не заменять реальной реализацией без явного запроса. Успешные мутации фото и лайков ничего не сохраняют.
- Успешный snackbar или изменение карточки через кеш Apollo не доказывают сохранение. Для этого нужно независимое чтение с сервера без клиентского кеша.
