# Ограничения rfr-api

Запуск и контракт API — в [README](README.md), разделение реальных функций и моков — в [таблице](README.md#что-реализовано-а-что-mock).

- Лента и статистика общие для всех пользователей: `withFriends` выбирает JSON, а не реальных друзей. Таблицы фото, лайков и статистики в миграциях не означают работающую реализацию.
- Сохраняй моки до явного запроса на замену. Создание, редактирование и лайк фото меняют только ответ; удаление возвращает `true` без удаления. Успешный ответ не подтверждает сохранение.
- Модель GraphQL генерируется из схемы DGS Codegen; сгенерированные классы не редактировать вручную.
- Профиль создаётся при первом `Query.user`. Связь с auth — по username, UUID в двух схемах независимы.
- Внешних ключей с каскадным удалением нет: перед удалением пользователя удаляются его строки в `friendship`.
