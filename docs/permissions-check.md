# Проверка проектных разрешений

Дата: 2026-11-03. Правила: `.codex/rules/project.rules`.

## Проверка правил

Выполнена штатным средством `codex execpolicy check --rules .codex/rules/project.rules -- <команда>`. Команды передавались как данные проверяющему средству, без выполнения push или удаления.

| Команда | До изменения | После изменения |
|---|---|---|
| `git -C . push` | Нет совпадения | `forbidden` |
| `git rm file` | Нет совпадения | `forbidden` |
| `unlink file` | Нет совпадения | `forbidden` |
| `mv file .file.<время>.bak` | `prompt` | `prompt` |
| Указанный ниже вызов `backup.ps1` | Нет совпадения | `allow` |

«Нет совпадения» не означает явного разрешения. Существующие разрешающие правила сохранены; контрольные проверки Gradle, Docker Compose, npm и `ports.sh` вернули `allow`, без запуска этих команд.

```powershell
powershell.exe -NoProfile -NonInteractive -File C:/Users/lazva/CodexProject/rfr/.codex/scripts/backup.ps1 -Path путь/к/файлу
```

## Фактические вызовы инструмента

Отказ инструмента выполнить три запрещённые команды **не проверялся**: опасные команды не запускались. Результат `forbidden` выше подтверждает решение проверяющего средства, а не фактическую блокировку вызова инструмента.

Вызов `backup.ps1` через инструмент выполнен на специально созданном временном файле. В этой сессии для записи в `.codex/tmp` использовался запрос повышенных разрешений; запуск без подтверждения фактически не подтверждён. Решение `allow` установлено проверкой файла правил.

## Проверка backup.ps1

На временных файлах фактически подтверждены:

- Переименование в соседний файл `.<имя>.<время>.bak`, исчезновение исходного имени и сохранность содержимого.
- Отказ при существующей копии: исходный файл и содержимое копии сохранены. Для воспроизводимой коллизии время было фиксировано только в проверочном процессе.
- Отказ для файла вне проекта с сохранением его содержимого.
- Отказ для каталога.

Скрипт также содержит проверку ссылок и junctions; отдельная фактическая проверка этой ветки не проводилась. Временные файлы оставлены на месте, удаление не выполнялось.

## Ограничения

- Закрыты только три указанных варианта команд. `git --no-pager push`, `git -c core.quotepath=false push`, `find . -delete` и `Remove-Item file` по результатам проверки остались без совпадения.
- Правила сопоставляют буквальные префиксы; произвольные сочетания параметров, другие пути к программам и обёртки не объявляются защищёнными.
- Отличие от исходного задания: обычный `mv` сохраняет `prompt`; решение `allow` предусмотрено для указанного вызова скрипта, проверяющего границы проекта и запрещающего перезапись копии.
- Проверка `.rules` отдельно не подтверждает загрузку этих правил работающей сессией. Проектная конфигурация должна быть доверенной; блокировка всех возможных обходов не гарантируется.

Код приложения, сервисы и тесты приложения в рамках этой проверки не изменялись и не запускались. Глобальные настройки не менялись; commit и push не выполнялись.
